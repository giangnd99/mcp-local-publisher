MCP

Kết nối Codex, OpenCode hoặc Claude Code

App tích hợp MCP server sẵn. Khởi động app rồi thêm địa chỉ này vào agent bạn dùng.

Xem lệnh kết nối cho từng agent
Codex
codex mcp add posting-management --url http://127.0.0.1:8085/mcp
OpenCode
opencode mcp add posting-management --global --url http://127.0.0.1:8085/mcp
Claude Code
claude mcp add --transport http posting-management http://127.0.0.1:8085/mcp --scope user

Sau khi thêm, khởi động lại hoặc tải lại agent để nó nhận danh sách công cụ MCP.
